# StripView

Offline WPF (.NET 8) companion for a 440x1920 USB case LCD strip. No network, no cloud.

Build: `dotnet build src\StripView\StripView.csproj -c Debug`
Run:   `src\StripView\bin\Debug\net8.0-windows\StripView.exe`

This build never opens or writes a serial port. Push once / Send to panel are preview-only.
